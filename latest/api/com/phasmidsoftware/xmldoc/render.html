case class StateR(maybeName: Option[String], attributes: SmartBuffer, interior: Boolean) extends AutoCloseable

Case class intended to take care of the state of rendering. Rendering is complex for several reasons: (1) a method such as render5 invokes render4, render3, etc. in order to process all of the members of a Product. (2) attributes are special and need to be rendered within the opening tag of the top-level element.

Case class intended to take care of the state of rendering. Rendering is complex for several reasons: (1) a method such as render5 invokes render4, render3, etc. in order to process all of the members of a Product. (2) attributes are special and need to be rendered within the opening tag of the top-level element.

NOTE: attributes is mutable (it's a SmartBuffer). It is retained as we do operations such as setName, recurse. However, we must be careful to ensure that no attribute gets left behind.

Value parameters

attributes

a (private) SmartBuffer: accessible via addAttribute or getAttributes.

interior

false if we are at the top level of an element; true if we have been invoked from above.

maybeName

an optional String.
