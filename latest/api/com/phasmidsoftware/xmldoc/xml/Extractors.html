Extractor which will convert an Xml Node into an instance of a case class with one member.

NOTE: this specific extractor provides logging. CONSIDER adding logging to the other extractors.

NOTE on naming P0's corresponding field in T: unless overridden via fields, the field name is matched against the node according to fieldExtractor's convention - a leading underscore (e.g. _id) means "this is an XML attribute", a plain name means "look for a child element of that name". Getting this wrong is a common way for extraction to fail with a MissingFieldException that otherwise looks like a real error in the data.
