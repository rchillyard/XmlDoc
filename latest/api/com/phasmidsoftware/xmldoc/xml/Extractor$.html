the name of a member field: if the (text) content of the node, then the field should be "$"; if a singleton child, then field is as is; if an attribute, then field should begin with "_"; if an optional child, then field should begin with "maybe" (the tag looked up is lower-case-initial by default, e.g. "maybeStyleUrl" looks for "styleUrl", but falls back to the capitalized form, e.g. "ExtendedData", if that's not found).
