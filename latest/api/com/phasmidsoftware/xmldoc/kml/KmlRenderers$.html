KmlRenderers

com.phasmidsoftware.xmldoc.kml.KmlRenderers
object KmlRenderers extends Renderers

Object KmlRenderers extends the Renderers base trait and serves as a collection of formatting utilities specifically for KML (Keyhole Markup Language) rendering.

This object contains nested case classes and methods for handling formatting operations.

def sequenceRenderer[R : Renderer]: Renderer[Seq[R]]

Method to return a Renderer of Seq[R].

Method to return a Renderer of Seq[R].

NOTE: each element renders under its own type's name (no name override) - this is what's wanted for a polymorphic Seq (e.g. Seq[Geometry], mixing Point/LineString/Polygon/...), where every element's own distinct tag must be preserved. For a homogeneous Seq of a single, non-polymorphic type whose class name doesn't match its real tag (e.g. InnerBoundaryIs vs. the tag "innerBoundaryIs"), use sequenceRendererNamed instead.
